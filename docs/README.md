# Documentation de Skarden — le référentiel

## Ordre de lecture

1. [developpement.md](developpement.md) — l'arborescence, les commandes, les pièges d'outillage.
2. [invariants.md](invariants.md) — `INV-1`…`INV-3`, les contraintes non négociables.
3. [pratiques.md](pratiques.md) — comment le référentiel se vérifie, les tests, le cycle de livraison.
4. [clean-code.md](clean-code.md) — comment s'écrivent les outils de vérification, et ce que l'outillage fait respecter.
5. [conventions.md](conventions.md) — nommage des fiches et du code, langue, commentaires, commits.

## Ce qui n'est pas ici

- **Les décisions de format** — champs, valeurs autorisées, patron espèce, lot, installation et journal, plages de conditions et modes : le référentiel de cadrage [ssk-it/skarden-cadrage](https://github.com/ssk-it/skarden-cadrage). Le consulter par le skill `consulter-referentiel` avant de toucher à un schéma.
- **L'interface** : [ssk-it/skarden-web](https://github.com/ssk-it/skarden-web).
